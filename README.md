# Dopewars RU 0.4 — Харьков

Офлайн-прототип игры для Android на русском языке, основанный на игровой логике dopewars 1.6.2.

## Районы

1. Салтовка (бывший Бронкс)
2. ХТЗ (бывшее Гетто) — здесь расположены банк и ростовщик
3. Парк Горького (бывший Центральный парк)
4. Сумская (бывший Манхэттен)
5. Научная (бывший Кони-Айленд)
6. Павлово Поле (бывший Бруклин)
7. Одесская (бывший Куинс)
8. Новые Дома (бывший Статен-Айленд)

Рыночные параметры районов и порядок индексов не менялись, поэтому старые сохранения совместимы. Изменены также стартовые и путевые сообщения.

## В этой версии
- Исправлена конфигурация Kotlin-плагина, добавлены настройки Java 17.
- Подготовлен сценарий GitHub Actions для сборки **отладочного APK**.
- Версия приложения обновлена до 0.4, идентификатор `com.dopewars.ru` прежний.

## Получение APK через GitHub Actions
1. Создайте пустой **приватный** репозиторий GitHub.
2. Загрузите **содержимое** папки проекта в корень репозитория, в том числе каталог `.github` (он скрытый).
3. Откройте **Actions → Android debug APK → Run workflow**.
4. После успешного завершения откройте запуск и скачайте архив из блока **Artifacts** `DopewarsRU-Kharkiv-debug`.
5. Распакуйте архив, получите `app-debug.apk` и установите на Android вручную.

Альтернатива: откройте проект в Android Studio (JDK 17, SDK 35), дождитесь синхронизации Gradle и используйте **Build → Build APK(s)**.

**Важно:** локальная сборка APK в рабочей среде не выполнена (отсутствуют Android SDK/Gradle; недоступна загрузка из сети). Конфигурация подготовлена, но успешная компиляция ещё не подтверждена.

## Ограничения
Это прототип, а не полный порт оригинала: нет оригинальных NPC, боевой системы, здоровья, сетевого режима и полноценной таблицы рекордов; «дополнительная сумка» и атмосферные события — адаптированные механики. Сохраняется один лучший счёт.
